#  Food-Recipes-Website

A simple Food Recipes Website built using HTML, CSS. This website showcases a variety of delicious recipes with images, descriptions, and easy navigation.

##  Features
- Different categories of recipes (Breakfast, Lunch, Dinner, Snacks)
- Fully responsive design (Mobile + Desktop friendly)
- Attractive UI with food images
- Easy navigation between sections
- Clean and user-friendly interface

## Technologies Used
- HTML5
- CSS3
